# DevAfrik

Plateforme d'échange entre développeurs africains : partage de bugs et discussions, pour les devs, par les devs.

Équipe : MD-TECH (Sénégal)
Démo : https://dapper-mochi-b74779.netlify.app/

## Fonctionnalités
- Inscription et connexion (mots de passe hachés, blocage après 5 échecs)
- Bugs et discussions avec extrait de code, réponses, votes, statut « résolu »
- Les 54 pays africains : filtre par pays, type et mot-clé
- Mode clair et sombre, adapté au téléphone

## Technologies
HTML, CSS, JavaScript, hébergé sur Netlify.
